# AutoTrade 公开运行记录

A股 ETF 日频信号系统的自动化运行记录：每交易日收盘后生成次日交易指令，
以模拟盘按既定限价规则推演成交，并公开净值与持仓（比例口径）。

- 页面：https://tiankuizhang.github.io/autotrade-report/
- **指令在执行前一晚公开**，事后不可修改（git 历史为证）——事前公开、事后可验
- 只公开比例（权重、盈亏、归一化净值），不公开金额、份数与账户规模
- 源码与需求文档保存在私有仓库；本仓库仅存放自动生成的静态页面
